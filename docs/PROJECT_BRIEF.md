# PROJECT_BRIEF — VoiceMouse 语音鼠标

- 一句话定位：把鼠标按键变成语音输入快捷键的桌面效率工具。
- 目标用户：中文办公用户，需要在浏览器/微信/Word 等场景快速语音输入。
- 核心任务：单击指定鼠标按键（中键/侧键）→ 触发系统语音输入（Windows 听写 / macOS 听写）。
- 本地/联网：纯本地，无任何网络通信，不采集数据。
- 免费/商业：免费开源（MIT）。
- 支持平台：Windows x64、macOS arm64（Apple Silicon）。
- 预计维护周期：长期，随个人使用需求迭代。
- 是否处理隐私数据：不处理；仅使用系统辅助功能监听鼠标/键盘，触发系统语音。
- 是否商店上架：否，GitHub Release 分发。
- 首版不做：自动更新、ARM64/Intel 平台、签名公证、移动端。
