## 安装与升级测试（未自动化，Release 前人工）

- Windows：干净安装 / 覆盖安装 / 中文路径 / 非管理员账户。
- macOS：解压运行 / 首次打开右键放行 / 覆盖旧版本数据保留。

## 异常与恢复

- 权限被撤销 → UI 提示且不崩溃。
- settings.json 损坏 → 自动回退默认设置（已实现：loadSettings catch）。
- 重复启动 → 单实例锁拒绝。
- 触发失败（快捷键无效）→ Toast + 弹窗提示，不崩溃。
